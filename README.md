# Student Management System

A console-based student management application developed using Java Core.

## Features

- Add a student
- Remove a student by ID
- Search for a student by ID
- Display all students
- Validate student IDs using Regular Expressions
- Validate GPA (0–10)
- Prevent duplicate student IDs
- Handle invalid input and exceptions

## Technologies

- Java 17
- Object-Oriented Programming (OOP)
- ArrayList
- Exception Handling
- Regular Expressions
- Scanner for console input

## How to Run

1. Clone or download this repository.
2. Import the project into Spring Tools for Eclipse.
3. Run `Main.java`.
4. Follow the console menu to manage students.

## Learning Objectives

This project demonstrates Java Core fundamentals, encapsulation, collections, input validation, and custom exception handling.
